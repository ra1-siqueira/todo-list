
    Cheatsheet:

  {YELLOW}add <tarefa>{RESET}  -> adiciona uma tarefa
  {YELLOW}rmv <tarefa>{RESET}  -> remove uma tarefa
  {YELLOW}done <tarefa>{RESET} -> marca/desmarca uma tarefa como feita
  {YELLOW}pin <tarefa>{RESET}  -> fixa/desfixa uma tarefa
  {YELLOW}dly <tarefa>{RESET}  -> marca/desmarca uma tarefa como diária
  {YELLOW}umrkall{RESET}       -> desmarca todas as tarefas
  {YELLOW}cl{RESET}            -> limpa a lista
  {YELLOW}rfsh{RESET}          -> recarrega a lista
  {YELLOW}ex{RESET}            -> finaliza o programa


    Observações:

* Ao ser fixada, uma tarefa não pode ser removida.

* Se uma tarefa é diária e foi concluída num dia,
  no dia seguinte ela voltará ao estado pendente.

* Caso o programa tenha ficado rodando de um dia para o outro
  e o estado da tarefa diária não tenha sido atualizado, rode
  o comando 'rfsh'.
